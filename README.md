# Flip 7 Score

Flip 7: With a Vengeance 用4人スコアボードPWA。

## 対応モード
- 通常モード
- 殺伐モード（Brutal Mode）

## 殺伐モードの実装
- ラウンド得点が0未満になり得る
- BUST後でもマイナス修正カードを受けられ、負のラウンド得点になる
- Flip 7達成時に「自分 +15」または「他プレイヤー −15」を選択可能
