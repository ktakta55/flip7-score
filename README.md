# Flip 7 Score v5

Galaxy Z Fold8 展開画面向け。

## v4変更点
- プレイヤー数を2〜8人で変更可能
- 画面上部の「設定」から変更
- 目標点も設定画面から変更可能
- Fold8展開時の人数別レイアウト調整
  - 2人: 2列
  - 3人: 3列
  - 4人: 4列
  - 5〜6人: 3列
  - 7〜8人: 4列
- 通常モード / 殺伐モード対応
- v1〜v3の保存データを引き継ぐ

## v5変更点
- 各プレイヤーに「合計」を追加
- 合計は「累計 + 今回」をリアルタイム表示
- ラウンド確定前でも、その時点で確定した場合の総得点を確認可能
