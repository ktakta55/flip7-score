# Flip 7 Score v6

Galaxy Z Fold8 展開画面向け。

## v4変更点
- プレイヤー数を2〜8人で変更可能
- 画面上部の「設定」から変更
- 目標点も設定画面から変更可能
- Fold8展開時の人数別レイアウト調整
  - 2人: 2列
  - 3人: 3列
  - 4人: 4列
  - 5〜6人: 3列
  - 7〜8人: 4列
- 通常モード / 殺伐モード対応
- v1〜v3の保存データを引き継ぐ

## v6変更点
- 各プレイヤーに左右の並び替えボタンを追加
- 名前を変えずに、その日の座り順・プレイ順を簡単に変更可能
- ラウンドごとにスタートプレイヤーを自動で次の人へ移動
- 画面上部に「このラウンドのスタート: ○○」を常時表示
- ラウンド確定後は次ラウンドのスタートプレイヤーを選択状態にする
- 1R戻すとスタートプレイヤーも1人分戻す
